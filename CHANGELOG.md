# Optimization Changelog

## Version 1.1

### Performance Improvements

- Converted hero image to WebP
  → Reduced image size by 70%.

- Added loading="lazy" to service images
  → Faster initial page load.

- Added defer attribute to JavaScript
  → Prevented render blocking.

- Removed unused CSS rules
  → Reduced stylesheet size.

- Compressed all images
  → Improved Lighthouse Performance score.

### Accessibility Improvements

- Added alt text to every image
  → Improved screen reader support.

- Added labels to contact form
  → Better accessibility for assistive technologies.

- Improved text/background contrast
  → Better readability.

- Corrected heading hierarchy
  → Better semantic structure.
